🎬 BiliPace｜Bilibili Playback Speed Manager

A playback speed extension designed specifically for Bilibili, giving you precise control over the pace of every video.

⚡ Fine-Grained Speed Control
1.5× too slow? 2.0× too fast? Set exactly the speed you want! Adjust playback speed effortlessly with a slider, precise numeric input, or increment and decrement buttons.

🎯 Rule-Based Speed Matching
Want to speed up tutorials but slow down music? Set different playback speeds for videos containing specific keywords. For example, play "Tutorial" videos at 2× and "Music" videos at 1×, with speeds applied automatically.

✨ Seamless Integration
No need to switch between interfaces. BiliPace seamlessly integrates into Bilibili’s native player controls, keeping everything right where you expect it.

🚀 More Useful Features
Quickly switch between commonly used speeds, drag to adjust keyword priority, and freely customize the supported speed range and step size.

🔓 Fully Open Source
The project is completely open source, with transparent code for a trustworthy experience.
